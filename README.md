# 💖 Harshita's Interactive Birthday Surprise Website 🎂✨

A mini **"Unlock the Memories"** interactive web adventure built with **Next.js 14, React, Tailwind CSS, Framer Motion, and Web Audio API Synthesizer**.

---

## 🌟 Interactive Story Flow

1. 🔐 **Secret Gate (Landing & Password)**
   - Glowing lock icon with animated particles & ambient starry sky.
   - Enter secret passcode (default supports `harshu`, `harshita`, `bestie`, `1234`, `cutie`, or your custom password).
   - Playful error shakes & hint popup.
   - Smooth unlock chime and heart burst transition.

2. 🧩 **Scrambled Photo Jigsaw Puzzle**
   - *"Before you can enter… put us back together 🧩❤️"*
   - Interactive 3x3 tile puzzle with drag & drop or click-to-swap mechanics.
   - Live piece placement counter (`X / 9 pieces placed`).
   - "Preview Guide" toggle, "Hint" helper, and "Magic Wand" auto-solver.
   - Solved state with golden border, victory fanfare, and star burst explosion.

3. ❓ **The Connection Question (Inside Joke / Trivia)**
   - *"One tiny question only the real Harshita could answer… ❓✨"*
   - Multiple choice or free-text input mode.
   - Interactive feedback with witty hints for wrong answers.
   - Radiant green/pink unlock glow upon answering correctly.

4. 🎂 **The Grand Birthday Reveal**
   - Dramatic blackout & radiant celebration reveal.
   - 🎵 Built-in Web Audio API melodic **Happy Birthday song** & ambient Lo-Fi chords.
   - 🎉 Multi-cannon confetti explosion with sparkles and star bursts.
   - ✨ Glowing animated typography: **"Happy Birthday Harshita! 🎂✨"**
   - Interactive birthday cake: click candles to make a wish & blow them out with realistic smoke animations!
   - Poppable floating balloons!

5. 📸 **Precious Memories Carousel & Scrapbook**
   - 3D horizontal card slider with touch swipe, arrow navigation, and dot indicators.
   - "Scrapbook Grid" view toggle.
   - ❤️ Heart reaction counter (click to send infinite love +1s).
   - 🔄 3D card flip to read the heartwarming backstory behind each memory.
   - 🔍 Lightbox zoom modal for full-resolution photos.

6. 💌 **Heartfelt Letter (Wax-Sealed Envelope)**
   - 3D interactive envelope with golden wax seal ("H").
   - Click to break seal & unfold the parchment letter.
   - Rich typography with highlighted quotes and signature.
   - 🤗 "Send a Virtual Hug & Reply" interactive response modal.
   - 📋 "Copy Letter" to clipboard & replay options.

7. ⚙️ **Live Customizer / Settings Panel**
   - Edit Harshita's name, password & hints.
   - Upload custom photos or change URLs for puzzle and memories.
   - Edit trivia question, answer options, and explanation.
   - Edit letter greeting, body paragraphs, and signature.
   - ⚡ Fast stage jumper to instantly preview any stage.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS + Custom Glassmorphism & Aurora Gradients
- **Animations**: Framer Motion
- **Confetti**: `canvas-confetti`
- **Audio**: Web Audio API Synthesizer (100% offline, zero broken audio links)
- **Icons**: Lucide React
